# M0 偏移 / CFI 与标注探针

日期：2026-10-16。环境：Node 22.22.3、Electron 44.7.2、foliate 指定 commit。

## 结论

采用方案 A：主进程 fflate 解包、linkedom XML DOM，使用 foliate 的 `fromRange` / `fromElements` 生成路径。文本按 DOM 解码后的 UTF-16 单元计数，保留空白，不做 Unicode 归一化。每段文本记录全章区间及节点起始 CFI；相邻文本节点在 CFI 中属于同一逻辑块，必须累加节点起始偏移。

| 验证                                         | 实测                                      |
| -------------------------------------------- | ----------------------------------------- |
| 合成 EPUB，5 章，固定随机种子抽样 200 个偏移 | 0 不一致（0%）                            |
| 跨内联元素、XML 实体解码、空白与代理对       | 样本覆盖，浏览器 Range 逐 UTF-16 单元一致 |
| 真实 EPUB 的另 200 个偏移                    | 未实跑，环境变量未提供；E2E 自动跳过      |
| 标注注入前 / 移除后 / 恢复后的位置 CFI       | 三者完全相同                              |
| 重启后恢复当前页 CFI                         | E2E 通过                                  |

首次抽样为 5 / 200 不一致，原因是实体解码后 linkedom 会拆出相邻文本节点；修复节点起始偏移累加后为 0 / 200。方案 A 已达标，无需方案 B。

## 标注方式

采用 CSS Custom Highlight API，不包裹或拆分正文节点。实测默认下划线 `underline` / `1px` / `5px` 偏移可用；截图确认有实线，悬停为类型全色 1.5px，无背景。命中测试使用 `caretPositionFromPoint` 和 Range，250ms 后出卡；当前行保持可见。

## 集成注意

- 保留 4% 栏间距。零间距会使分页器把前一栏恰好贴边的文本算入后一页，导致保存的 Range 起点错误；恢复少量间距后重启恢复测试通过。版心容器 680px，正文实际行宽约 34 字。
- 阅读器就绪需等章节字体就绪和排版帧完成，避免字体重排后命中坐标漂移。
- 上游为 WebKit 兼容而给 iframe 开放脚本；仅移除两处 `allow-scripts`，见 D-37（待 review）及 VENDOR.md。实际 iframe 无脚本权限，合成脚本未执行。
- 没有真实书验收；不同出版 EPUB 的异常结构仍需补充运行验证，不将合成样本的 0% 外推为所有书籍均兼容。

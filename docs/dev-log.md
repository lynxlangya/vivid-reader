## Review 修复 · 顺读相邻校验 · 2026-10-16

### 问题

Claude Code 复核时发现：主进程判定“顺读”只看渲染进程上报的 `next` 和上一页起点不超过边界，不检查新页是否紧接上一页。渲染进程的 `next` 标记可能过期，例如书末 `next()` 没有触发翻页，随后点了书内链接。这时主进程会把一次远跳当作翻页，5 秒后边界被推到后文。改前用真实 IPC 复现：边界从第一章开头跳到第四章开头。

### 修复

- `ContentGateway.follows`：在主进程把上一页终点和新页起点映射为“章节 + 偏移”，中间（可跨章）不能有被跳过的非空白文字；新页早于上一页起点、CFI 非法时判为不相邻。

- 误判为不相邻只会让边界晚一页，下一次相邻翻页即可恢复；误判为相邻才会越界，所以容差定为 0 个非空白字符。没有新增产品或架构决定，没有新增依赖，渲染进程不改。

## Review 修复 · 阅读器加载中卸载 · 2026-10-16

### 问题

复核中，“导入、200 偏移往返、悬停与恢复”这条 E2E 偶发失败，失败时“开始阅读”没有出现；单独重复运行时约 30% 失败。前面“顺读相邻校验”一节记录的那次未定位超时也是这个问题。最初推测是启动恢复完成前的导入点击被吞掉，核对后不成立：导入按钮已在恢复完成前禁用。

实际根因：启动恢复后阅读器正在打开书，此时点击导入或书架会卸载阅读器。foliate 的 `open()` 会立即创建分页器，但其内部视图要等 `init()` 显示首个章节后才存在。卸载时 `close()` 对尚未创建的内部视图调用 `destroy`，错误抛在 React 的 effect 清理中，整个界面空白，只能重启。若卸载发生在 `init()` 进行中，关闭会导致 foliate 后续流程读取已置空的视图；若只是不关闭，宿主节点被移除后 iframe 失去 document，分页器的尺寸监听和渲染流程继续报错并残留。书越大，加载窗口越长，真实使用中也会触发。

### 修复

- 只改 `Reader.tsx` 的生命周期，不改 foliate 源码。
- 加载中不调用 `close()`；加载流程结束时若阅读器已卸载，由它自行关闭并移除视图。
- 卸载时若仍在加载，在 layout effect 清理阶段（React 移除宿主节点之前），用 `moveBefore` 把视图原样移入页面外的隐藏容器（inert、aria-hidden、不可见）。`moveBefore` 不会重载 iframe；Electron 44 对应 Chromium 152，已实测 iframe document 移动前后为同一对象。加载完成后正常关闭，并移除视图与容器。

### 测试与验证

- 新增 E2E：书架与阅读器之间快速往返 21 轮，卸载延时从 0 到 200ms 扫描。断言渲染进程无错误、最终阅读器可用、页面只剩一个 foliate-view 且没有残留的隐藏容器。改前 3/3 失败；只做“加载中不关闭”时仍 5/5 失败；完整修复后 5 + 3 + 3 次全部通过。

### 背景

- 把这组真实 relocate 序列交给主进程的 `position`、`follows`、`advanceBoundary` 离线回放，每页都停留满 5 秒：修复前，读完全书后边界仍停在第 0 章（740 次翻页中 699 个正文页边界落后）。

### 问题（同时存在四处，任意一处都会让边界永久停住）

1. `validateCFI` 不接受起点为空的区间 CFI（如 `,,/1:55`）。foliate 在页面恰好从段落元素开始时会这样写。全书 35 页受影响，`vivid:relocate` 抛错，界面显示“位置暂时未能保存”。封面页就是这种形式，所以打开书就出错。
2. `follows()` 要求两页之间没有任何非空白字符。foliate 的可见区间会漏掉行尾被挤压的标点：全书 200 次正常翻页留下 1 个非空白字符的缺口，类型多为句号、问号。
3. 跨章时一次 `next()` 先报旧章末尾的空白栏，再报新章第一页。阅读器在第一次 relocate 后就把模式重置为 `jump`，新章第一页于是被当作跳转。
4. foliate 加载新章时会连续多次报告同一页（本书每次跨章 4 次）。重复的 relocate 被状态机当作“越过边界的翻页”，清掉了等待中的 5 秒停留。

### 修复

- `validateCFI` 允许区间的起点或终点为空。
- `follows()` 允许至多 2 个非空白字符的缺口（`PAGE_GAP`；实测最大为 1）。陈旧的 next 或跳转跳过的文字远多于此，防剧透不受影响。
- 新增 `src/renderer/reader/navigation.ts`：一次翻页在 `next()`/`prev()` 返回之前产生的所有 relocate 都带这次翻页的模式；较早翻页的结束不会清掉较新的翻页或跳转。
- `advanceBoundary` 收到与当前页相同的 relocate 时，状态原样保留。

### 测试与验证

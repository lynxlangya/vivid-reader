# 愿景 · Vision

## 起源

一个晚上读《枪炮、病菌与钢铁》（中译本），书里出现大量陌生的岛名、地名、族群名。每遇到一个，注意力就被拉出书页：这个地方在哪？离哪儿近？那里的人长什么样、什么肤色、风土人情如何？脑海里没有画面，只能空想，阅读节奏被一次次打断。

## 要解决的问题

**不是"读不懂"，而是"看不见"。**

文字给出了名字，却没给出画面。读者被迫在脑中凭空构图，这既耗神又容易出错。历历要做的是：在最需要的那一刻，用最少的打扰，补上那张画面——然后让读者立刻回到书里。

衡量成功的唯一标准：**读书时分神的次数是不是变少了，读书是不是更有意思了。**

## 核心体验（"啊哈时刻"）

> 鼠标停在"查塔姆群岛"上，一张真实地图浮现：新西兰以东八百公里外的一小片岛屿。下面一行字告诉你，在本书这一章里，它是莫里奥里人生活的地方。看一眼，懂了，继续读。

## 产品原则

1. **阅读是主角，AI 是配角。** 阅读器必须先是一个好用、安静的阅读器。任何 AI 功能都不能比书本身更吵。
2. **真实优先于生成。** 地图用真实地理数据，历史人物用真实画像；AI 生成图像只用于没有照片可用的场景示意，并且明确标注"AI 示意"。
3. **不剧透，守住阅读的乐趣。** 伴读只知道你读过的内容。这是工具层的硬约束，而不是对模型的嘱咐。
4. **语境优先于百科。** 解释的是"这个词在本书此处指什么"，而不是通用定义。
5. **稀疏胜于密集。** 满屏高亮等于没有高亮。只标注值得标注的，已知的不再打扰。
6. **随读随长。** 知识图谱、足迹地图随阅读进度逐步点亮，进度本身就是乐趣。
7. **按需而非强塞。** 总结、深入解释、画图都由读者主动发起，绝不自动弹出。
8. **尊重族群。** 本书恰恰在反驳"种族优劣论"。涉及族群样貌时，不让 AI 凭刻板印象作画，优先真实的人类学 / 博物馆资料。
9. **本地与隐私。** 书在本地，数据在本地；只有必要的片段发给模型。仓库永不包含书籍内容。

## 不同书，不同的"画面"

MVP 只服务《枪炮》这一本书，但设计上预留按书籍类型切换可视化方式的空间：

| 书籍类型 | 最有价值的可视化 |
|---|---|
| 历史 / 地理非虚构 | 地图 + 时间轴 |
| 小说 | 人物关系图 + 人物形象 |
| 论证 / 社科 | 论点结构图、因果脑图 |
| 传记 | 人生时间线 + 足迹地图 |

《枪炮》本质上是论证型的，它的骨架是一条因果链：

> 地理轴向 → 可驯化物种 → 粮食生产 → 人口密度 → 病菌 / 文字 / 技术 / 国家 → 征服

一张随章节逐步构建的因果脑图，可能是这本书最好的"画面"之一（v0.3）。

## 参考与差异化

- **Kindle X-Ray**：人名、地名速查的简化版。历历多了地图、语境释义与进度感知。
- **微信读书 AI 问书**、**Readwise Reader Ghost Reader**：对话式辅助阅读。
- **[ReadAny](https://github.com/codedogQBY/readany)**：开源 AI 电子书阅读器（语义搜索、RAG 对话），可参考其阅读器实现。

历历的差异化：**可视化（尤其是真实地图）+ 严格跟随阅读进度。**

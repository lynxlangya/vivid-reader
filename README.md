# 历历 · Vivid

> 晴川历历汉阳树。——崔颢《黄鹤楼》
>
> 读到哪里，哪里就历历在目。

**历历** 是一个带 AI 伴读的 macOS 桌面电子书阅读器。

读《枪炮、病菌与钢铁》时，书里满是查塔姆群岛、卡哈马卡、新几内亚高地、莫里奥里人……脑子里没有画面，就会忍不住分神去想"这地方在哪""这人长什么样"。历历想做的事很简单：**鼠标移上去，地图和释义就在眼前，看一眼，回到书里。**

## 它做什么（MVP）

- **阅读器优先**：打开 EPUB，安静地读。阅读是主功能，AI 是陪衬。
- **悬停一瞥**：书中的地名、人物、族群、物种被稀疏地标注出来；悬停即可看到**真实地图**、基础信息，以及"**在本书此处**它指什么"的语境释义。
- **伴读，而不剧透**：AI 伴读只知道你已经读过的内容——这是在工具层强制截断的，不靠提示词约束。
- **逐步生长**：你读得越多，见过的地方和人物越多，知识图谱随你的进度一点点点亮。
- **按需总结**：想总结时再总结（选中段落 / 本章 / 至今），从不自动塞给你。

# 路线图 · Roadmap

原则：**先拆风险最大的部分**；每个里程碑都有明确的验收标准；MVP 只服务《枪炮、病菌与钢铁》中译本 EPUB。

---

## v0.1 · MVP

### M0 · 技术探针
用最少的代码验证阅读器这条路能不能走通。
- [ ] Electron + React + foliate-js 打开《枪炮》EPUB，正常翻页、显示目录
- [ ] 在 iframe 正文中注入一个**硬编码**的实体标注，悬停弹出一个简单卡片
- [ ] 读取、保存阅读位置（CFI）
- [ ] 主进程通过 `pi-ai` 跑通一次 DeepSeek 调用
- [ ] 验证"文本偏移 ↔ CFI"映射方案

**验收**：能打开书、能翻页、悬停硬编码的词能弹出卡片，DeepSeek 能返回结果。

### M1 · 抽取质量
**整个项目最关键的一步。** 中文地名匹配不准，后面做得再好看也没用。
- [ ] 只跑第 1～2 章：实体抽取 → 合并 → 链接 Wikidata
- [ ] 做一个简单的核对页面，人工逐条检查
- [ ] 统计：抽取召回、链接准确率、未链接比例、成本与耗时
- [ ] 迭代 prompt 与消歧策略

**验收**：地点类实体链接准确率 ≥ 90%（目标值，可调整），测出全书预处理的实际成本。

### M2 · 悬停卡片（啊哈时刻）
- [ ] 全量预处理结果写库，阅读器按章节注入稀疏标注
- [ ] 悬停卡片：真实地图 + 基础信息 + 语境释义 + "第 X 章初见"
- [ ] 打开章节时后台预取本章释义
- [ ] "标为已知"、"纠错"（从 Wikidata 候选中选择或手动搜索）
- [ ] 已读边界的记录与推进

**验收**：自己读一周，主观感受分神次数明显变少；悬停到卡片出现的延迟基本无感。

### M3 · 伴读对话
- [ ] `pi-agent-core` 装配读书工具集，所有工具按已读边界截断
- [ ] 伴读栏：对话、引用位置跳转
- [ ] 快捷总结：选中段落 / 本章 / 至今
- [ ] 防剧透测试：构造"问后文"的问题，确认模型拿不到边界后的原文

**验收**：能流畅地边读边问；后文原文不会出现在任何工具的返回结果里。

### M4 · 打磨与开源准备
- [ ] 全书跑通，修正纠错流程中的问题
- [ ] 设置页：API Key、模型选择、标注密度、字体 / 字号 / 主题
- [ ] 书架页
- [ ] README、截图、许可证、贡献指南
- [ ] 确认仓库中没有任何书籍内容或衍生缓存

**验收**：干净的仓库里，别人自备 EPUB 和 API Key 就能跑起来。

## v0.2 · 看见更多
- **足迹地图**：一张图展示已读范围内出现过的所有地点，随进度点亮（预处理数据已具备，成本低；如果 M2 顺利可提前）
- **AI 场景示意图**：通过 `generateImages()` 调用 GPT Image，只用于没有照片的场景，标注"AI 示意"，生成结果缓存
- **真实人物画像**：接入 Wikimedia Commons，标注出处
- **知识图谱（初版）**：人物、地点、族群之间的关系，随阅读进度生长

## v0.3 · 看见结构
- **因果脑图**：针对《枪炮》这类论证型书籍，随章节逐步构建论证链
- **时间轴地图**：农业扩散、南岛语族迁徙等，拖动时间条查看
